# Доменный модуль генерации колоды карт и стартовой раздачи

## Описание
Реализовать доменный модуль генерации колоды карт в строгом соответствии с реестром допустимости Приложения А в зависимости от количества участников ($N$ от 4 до 12) и логику стартовой раздачи на руки игрокам.

## Требования
- [x] Создать перечисления и доменные классы карт: `Card`, `CardType` (`EVENT`, `PANIC`), `CardName` (для всех 108 карт реестра).
- [x] Реализовать сервис `DeckFactory` с выборкой карт по порогу минимального количества игроков согласно таблице А.3.
- [x] Реализовать сборку стартового набора: ровно 1 карта «Нечто» (карта №1) + $(4 \times N - 1)$ случайных карт без паники и заражений.
- [x] Реализовать перемешивание и распределение стартового набора: ровно по 4 карты на руку каждому игроку.
- [x] Сформировать общую колоду добора из всех оставшихся карт (включая все «Заражения» и «Панику»).
- [x] Написать unit-тесты для проверки состава колоды и раздачи при $N = 4, 6, 8, 12$ участниках.

## Критерии приёмки
- [x] Модульные тесты проверяют корректность генерации колоды для всех граничных значений числа участников ($4 \le N \le 12$).
- [x] В стартовом наборе на всех участников гарантированно присутствует ровно 1 карта «Нечто» и отсутствуют карты паники и заражения.
- [x] Каждому игроку после раздачи выдаётся ровно 4 карты на руку.
- [x] Тесты выполняются одной стандартной командой Maven и подтверждают 100% прохождение в CI.
