# Нечто — Frontend

Telegram Mini App для игры «Нечто». React + TypeScript + Vite.

## Требования

- Node.js 20+
- npm

## Установка

```bash
cd apps/frontend
npm install
```

## Настройка окружения

Скопируйте файл с примером переменных окружения и при необходимости укажите адрес API:

```bash
cp .env.example .env
```

| Переменная     | Назначение                         | По умолчанию            |
| -------------- | ----------------------------------- | ------------------------ |
| `VITE_API_URL` | Адрес backend API (Java)            | `http://localhost:8080` |

## Запуск в режиме разработки

```bash
npm run dev
```

Приложение будет доступно по адресу, который выведет Vite (обычно `http://localhost:5173`).

## Проверка внутри Telegram

Для локальной проверки как Telegram Mini App используйте туннель (например, ngrok) и укажите
полученный HTTPS-адрес в настройках бота у [@BotFather](https://t.me/BotFather) (`/setmenubutton`
или `/newapp`).

## Сборка

```bash
npm run build
```

Собранные файлы появятся в каталоге `dist`.

## Линтинг

```bash
npm run lint
```

## Статус

На данном этапе (FE-1) реализован только стартовый экран интерфейса: заголовок «Нечто», кнопки
«Создать игру» и «Присоединиться к игре», поле ввода кода комнаты. Игровая логика и запросы к
серверу будут подключены на следующих этапах.
